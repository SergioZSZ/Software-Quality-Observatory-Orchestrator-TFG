Tools

In this web, you will find the tools developed by the OEG.

OOPS! - OntOlogy Pitfall Scanner!

Ontology services

OOPS! - OntOlogy Pitfall Scanner! Tool that detects common pitfalls in ontology development. Users enter a URI or paste an OWL document, and OOPS! reports the pitfalls found.

OnToology

Ontology services

OnToology System to automate part of collaborative ontology development, producing diagrams, documentation and validation from ontology repositories.

Loupe - The Linked Data Explorer

Linked Data services

Loupe - The Linked Data Explorer Online tool for inspecting dataset structure, understanding data, formulating queries and detecting quality issues.

Leire

Linguistic

Leire Tool that reads lexicalizations and applies consistency checks for each design pattern.

Lemon Assistant

Linguistic

Lemon Assistant Tool to create Lemon Patterns and ontology lexicons for lexicalizing ontologies.
